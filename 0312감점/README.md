# pwd 명령어 정리

## pwd란?

pwd는 **Print Working Directory**의 약자로 현재 사용자가 작업 중인 디렉토리의 경로를 출력하는 명령어이다.

현재 위치를 확인할 때 가장 많이 사용하는 기본 명령어 중 하나이다.

사용 예시

```bash
pwd
```

실행 결과

```bash
/home/user/project
```

위 결과는 현재 사용자가 `/home/user/project` 디렉토리에서 작업하고 있다는 의미이다.

---

## 주요 옵션

### -L (Logical)

심볼릭 링크가 포함된 경로를 그대로 출력한다.

```bash
pwd -L
```

기본적으로 적용되는 옵션이며 사용자가 이동한 경로를 기준으로 보여준다.

### -P (Physical)

심볼릭 링크를 무시하고 실제 디렉토리 위치를 출력한다.

```bash
pwd -P
```

실제 파일 시스템 상의 물리적인 경로를 확인할 수 있다.

### --help

명령어 사용 방법을 확인한다.

```bash
pwd --help
```

### --version

현재 설치된 pwd 프로그램의 버전을 확인한다.

```bash
pwd --version
```

## 쉘 내장 pwd와 /bin/pwd

리눅스에서는 pwd가 두 가지 방식으로 동작할 수 있다.

### 쉘 내장 명령어

bash와 같은 쉘 내부에 포함된 pwd이다.

* 현재 작업 경로를 쉘이 직접 관리
* 일반적으로 가장 많이 사용
* 심볼릭 링크가 포함된 경로를 그대로 출력

### /bin/pwd

운영체제에 설치된 별도의 실행 파일이다.

```bash
/bin/pwd
```

* 파일 시스템을 직접 확인
* 실제 물리 경로를 조회
* 심볼릭 링크를 무시한 결과를 반환할 수 있음

## 관련 환경 변수

### PWD

현재 작업 중인 디렉토리를 저장하는 환경 변수이다.

```bash
echo $PWD
```

### OLDPWD

이전에 위치했던 디렉토리를 저장하는 환경 변수이다.

```bash
echo $OLDPWD
```

예를 들어 `cd -` 명령어를 사용하면 이전 디렉토리로 쉽게 이동할 수 있다.

---

## 정리

pwd는 현재 작업 위치를 확인하는 가장 기본적인 리눅스 명령어이다. 디렉토리 이동 중 현재 위치를 확인할 때 사용하며, PWD 환경 변수와 함께 쉘 스크립트 작성에도 자주 활용된다.
