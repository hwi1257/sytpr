# 🐚 Shell: The Bridge to the Kernel

셸(Shell)은 사용자와 운영체제의 핵심인 커널(Kernel) 사이를 중계하는 **명령어 해석기**입니다. 시스템 제어와 작업 자동화를 위한 필수적인 인터페이스입니다.

---

### 🏗️ 시스템 계층 구조

> **User** → **Shell** → **Kernel** → **Hardware**



---

### 🚀 핵심 기능

*   **Command 해석:** 사용자로부터 입력받은 명령어를 커널이 이해할 수 있도록 전달
*   **파이프라인 (`|`):** 여러 명령어를 연결하여 데이터 흐름 제어
*   **리다이렉션 (`>`, `>>`):** 표준 입출력을 파일로 전환
*   **자동화:** 반복적인 작업을 쉘 스크립트로 작성하여 효율성 증대

### 💻 주요 종류

| 종류 | 특징 |
| :--- | :--- |
| **bash** | 리눅스 표준 쉘 (높은 호환성) |
| **zsh** | macOS 기본 쉘, 강력한 플러그인(Oh My Zsh) 기반의 높은 생산성 |
| **fish** | 사용자 편의성에 특화된 자동 완성 기능 제공 |
