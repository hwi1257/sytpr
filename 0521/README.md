# Linux 명령어 및 시스템 관리 정리

## 검색 및 텍스트 처리 명령어

### find

시스템 내부에서 원하는 파일을 찾을 때 사용하는 명령어이다.

예시

```bash
find . -name "*.c"
```

현재 위치를 기준으로 `.c` 파일을 검색한다.

---

### grep

파일 안에서 특정 문자열이나 패턴을 검색할 때 사용한다.

예시

```bash
grep "main" test.c
```

`test.c` 파일에서 `main` 문자열이 포함된 줄을 출력한다.

---

### sort

텍스트 파일의 내용을 정렬하는 명령어이다.

* 오름차순 정렬
* 내림차순 정렬
* 숫자 기준 정렬

등 다양한 옵션을 사용할 수 있다.

---

### split / cat / paste

#### split

큰 파일을 여러 개의 작은 파일로 분할한다.

#### cat

파일 내용을 출력하거나 여러 파일을 하나로 합칠 때 사용한다.

#### paste

여러 파일의 내용을 열 단위로 합쳐서 출력한다.

---

### awk

텍스트 데이터를 가공하거나 특정 필드만 추출할 때 사용하는 강력한 도구이다.

예시

```bash
awk '{print $1}'
```

첫 번째 필드만 출력한다.

---

## 작업 예약 및 디스크 관리

### cron / crontab

정해진 시간에 자동으로 작업을 실행하기 위한 기능이다.

예시

```bash
crontab -e
```

작업 스케줄을 등록하거나 수정할 수 있다.

---

### at

특정 시점에 한 번만 실행되는 작업을 예약할 때 사용한다.

예시

```bash
at 10:00
```

오전 10시에 작업 실행.

---

### df

파일 시스템 전체의 디스크 사용량을 확인한다.

예시

```bash
df -h
```

---

### du

특정 파일이나 디렉터리가 사용하는 용량을 확인한다.

예시

```bash
du -sh *
```

---

### tar

파일이나 디렉터리를 하나의 아카이브 파일로 묶는다.

예시

```bash
tar -cvf backup.tar folder
```

---

### gzip

파일을 압축하는 명령어이다.

예시

```bash
gzip test.txt
```

압축 후 `.gz` 파일 생성.

---

## Bash 환경 설정

### Bash 시작 과정

사용자가 로그인하면 여러 설정 파일을 읽어 환경을 구성한다.

대표 파일

* /etc/profile
* ~/.bash_profile
* ~/.bashrc

---

### alias

긴 명령어를 짧게 등록하여 사용할 수 있다.

예시

```bash
alias ll='ls -al'
```

---

### history

이전에 입력한 명령어 목록을 확인할 수 있다.

예시

```bash
history
```

---

### 명령어 재실행

```bash
!!
```

직전에 실행한 명령 재실행

```bash
!100
```

100번 명령 실행

---

## 개발 환경 및 디버깅

### gedit

GUI 환경에서 사용할 수 있는 텍스트 편집기이다.

---

### gcc

C 언어 프로그램을 컴파일하는 컴파일러이다.

예시

```bash
gcc test.c -o test
```

---

### gdb

프로그램 실행 중 오류를 찾기 위한 디버거이다.

주요 기능

* 중단점(Breakpoint)
* 변수 확인
* 메모리 확인
* 실행 흐름 추적

---

### Makefile

여러 소스 파일의 컴파일 과정을 자동화하기 위한 파일이다.

예시

```bash
make
```

명령 한 번으로 빌드 가능.

## 파일 시스템

### 하드 링크(Hard Link)

원본 파일과 동일한 inode를 공유하는 링크이다.

원본 파일이 삭제되어도 링크가 남아 있으면 파일 데이터는 유지된다.

---

### 심볼릭 링크(Symbolic Link)

원본 파일의 경로 정보를 저장하는 특수 파일이다.

Windows의 바로가기와 비슷한 개념이다.

---

### open() 과 fopen()

#### open()

운영체제의 시스템 콜을 직접 사용한다.

#### fopen()

C 라이브러리 함수이며 내부적으로 open()을 활용한다.

---

## 프로세스 관리

### 프로세스 이미지

프로그램이 실행되어 메모리에 적재된 상태를 의미한다.

구성 영역

* Text
* Data
* BSS
* Heap
* Stack

---

### size

실행 파일의 메모리 사용 정보를 출력한다.

예시

```bash
size a.out
```

---

### PID

프로세스를 구분하기 위한 고유 번호이다.

예시

```bash
ps
```

명령으로 확인 가능하다.

---

## 시스템 관리

### sudo

일반 사용자가 관리자 권한으로 명령을 실행할 수 있도록 해준다.

예시

```bash
sudo apt update
```

---

### 시스템 부팅 과정

1. BIOS 또는 UEFI 실행
2. 부트로더(GRUB) 실행
3. Linux Kernel 로드
4. init 또는 systemd 실행
5. 사용자 환경 시작

---

### 시스템 종료 및 재부팅

종료

```bash
shutdown now
```

재부팅

```bash
shutdown -r now
```

---

### 데몬(Daemon)

백그라운드에서 동작하며 시스템 서비스를 제공하는 프로세스이다.

예시

* sshd
* httpd
* mysqld

사용자의 요청을 대기하며 지속적으로 실행된다.
